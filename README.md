# 钢琴谱集 · 四首可播放版

包含《阳光宅男》《IRIS OUT》《枫》《灶门炭治郎之歌》的原谱、完整音符数据和网页源代码。

## 本地打开

先解压，在本目录运行（Python 3）：

```sh
python -m http.server 8000 --bind 127.0.0.1 --directory dist
```

浏览器打开 http://127.0.0.1:8000 。不要直接双击 HTML：浏览器可能阻止本地 JSON 读取。播放本身不依赖 CDN 或外部音频服务。

曲目下拉框切换四首作品。开始／暂停、拖动谱面指针、点击谱面定位、调速、音量和自动跟谱均可用。底部键盘同步显示左右手和 C1/D1 等音名，中央 C 使用 C4。切换曲目停止前一首所有声音。

## 左右手等待练习

顶部「模式」选择「左手练习」或「右手练习」，点击「开始练习」。指针停在该手下一组起奏音上；按齐所有提示音才前进，错音不推进。和弦允许依次点击，以便鼠标使用。休止与延音线续接不要求额外按键；连续同音必须松开后重新按下。练习模式没有自动伴奏或节奏评分。

输入方式：
- 点击下方屏幕琴键（触屏支持多点输入）。
- 电脑键盘 A W S E D F T G Y H U J K 对应当前 C 到下一八度 C；选择起始八度，或使用 Z / X 调整。
- 点击「连接 MIDI 电钢琴」，在支持 Web MIDI 的浏览器授权连接。设备的 note-on / note-off 用于判断，不采集麦克风音频。普通声学钢琴不能直接通过声音识别。

可暂停、拖动谱面或切换曲目；跳转后等待所选位置之后的下一组音。切换模式或曲目会停止旧声音并清空已按音。网页失去焦点时暂停，以免遗漏按键释放。

检查覆盖四首曲目的左右手筛选、等待时钟、错音、和弦、连续同音、延音、暂停、跳转、末尾及切谱；MIDI 消息用模拟数据检查，未连接实体电钢琴实测。

## 文件

- `dist/`：可直接用 HTTP 静态服务部署的全部网页资源。
- `dist/score.json` 与根目录五张谱面图：《阳光宅男》数据。
- `dist/scores/`：另外三首的原 PDF、谱面图片和完整演奏数据。
- `source/score.pdf`：《阳光宅男》原 PDF。
- `scripts/extract_score.py`：原曲矢量提取器。
- `scripts/transcribe_vector_scores.py`：另外三首的字体、符干、连梁、连音和谱表提取。
- `scripts/reviewed_corrections.py`：复杂声部等经原谱检查的特定修正，未用统一缩放把小节硬凑成四拍。
- `scripts/export_performance.py`：音高、临时记号、谱号、八度线、延音、踏板和速度表导出。
- `transcription/`：保留字形与几何依据的提取结果，便于后续校正。
- `scripts/test_player.cjs`：无需浏览器的播放器状态和音频调度契约检查。

## 转写范围及演奏处理

| 曲目 | 页面 | 小节 | 四分音符总拍数 | 符头事件 |
|---|---:|---:|---:|---:|
| 阳光宅男 | 5 | 121 | 484 | 1889 |
| IRIS OUT | 5 | 85 | 340 | 2488 |
| 枫 | 7 | 76 | 306 | 2397 |
| 灶门炭治郎之歌 | 6 | 103 | 408 | 2819 |

《枫》第 4 小节是 6/4；《灶门炭治郎之歌》含 2/4 小节，以及一个跨行小节，在内部用两个两拍谱面片段表示，但界面保持同一小节编号。

音符、和弦、休止、变拍号、连音、临时升降号、换谱号、八度线与延音均从所附版本重建。支持踏板延长声音及相对速度变化。音色使用真实钢琴单音录音采样，不是歌曲录音。

演奏并非真人诠释：琶音和弦按同时和弦播放；自由延长记号不额外添加不定时停顿。装饰音采用短时值处理。原谱未给数值的渐慢、Meno mosso 和 morendo 使用固定的参考速度比例。《枫》未标节拍器速度，默认 72 BPM，可调整。这些处理不代表原演奏者的唯一速度或触键选择。

已检查曲目全页覆盖、事件音域和小节范围、谱面定位锚点、异步切谱、暂停清音、跳转后播放和变速时钟。状态检查使用 DOM／AudioContext 模拟，不能代替真实浏览器听音；复杂编配仍可能存在转写误差，保留提取依据便于继续校正。

## 重新生成新增三首

环境需 Python 3 与 PyMuPDF：

```sh
python scripts/transcribe_vector_scores.py all
python scripts/export_performance.py
node scripts/test_player.cjs
```

提取器针对这三份 PDF 校准；增加不同来源的五线谱时，需要重新检查字体、排版和音乐语义，不能直接假定任意 PDF 都可无误识别。

## 参考指法

勾选「显示参考指法」后，自动播放和左右手练习都会显示当前音的 1–5 指编号，并在琴键顶部显示「右 1」「左 5」等提示。1 为拇指，5 为小指。

指法由前后音、黑白键、和弦跨度和延音占指约束自动估算，使用有限候选路径搜索减少手位移动。它不是 PDF 原谱指法，也不保证适合所有手型。超过五音或超过八度的同时和弦、无法解决的持续声部冲突显示「待调整」，不硬给指法。可取消勾选隐藏。指法只作提示，按键练习仍只判断音高；屏幕、电脑键盘和 MIDI 均不能识别实际用了哪根手指。

## 真实钢琴音色

采用 Alexander Holm 的 Salamander Grand Piano（Yamaha C5）录音采样，由 Tone.js 分发，许可 CC BY 3.0。30 个原始立体声 MP3 根音覆盖 A0–C8，之间音高使用相邻样本移调，最多相差一个半音。全部采样约 2 MB，随网页及 ZIP 打包，首次播放时加载，之后在当前页面复用。

支持按 MIDI 力度调整音量与音色明亮度；松键按音域使用不同衰减，支持 MIDI CC64 延音踏板及原谱中的踏板延长。附带轻微算法空间混响和输出限幅；暂停、跳转、切谱清除旧声音及混响尾音。屏幕和电脑键盘采用固定力度。

这是原完整音库的单力度采样子集，没有包含原库的全部 16 个力度层或独立踏板／琴槌噪声录音。力度音色差异通过滤波模拟，空间响应由算法生成。音源署名与原 README 位于 `dist/audio/piano/SOURCE-LICENSE.txt`。

已验证 30 个 MP3 可正常解码、全 88 键的采样选择、力度滤波、松键包络，以及停止时清音。测试使用音频接口模拟，不代表不同浏览器与硬件均已实机听音测试。
